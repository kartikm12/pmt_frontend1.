## 1. See the team

![The Team tab of a project](1-team.webp "Everyone on the project and their project role")

Open the project and click **Team**. You see each person's job title [[1]], their **project role** [[2]] and how many tasks they have here.

## 2. Project roles

A project role only counts in this project:

| Project role | Can do |
| --- | --- |
| **Owner** | Everything a Manager can. Set when the project is created. |
| **Manager** | Add and change tasks, columns and the team, and edit the project |
| **Contributor** | Work on tasks: move cards, tick the checklist, comment, add files |
| **Viewer** | Look only |

To change someone's role, pick it from the list [[2]]. It applies at once.

:::note Company managers
Admins, Managers and Project Managers can manage every project, whatever their project role.
:::

## 3. Add or remove people

Click **Edit Project** and change **Project Team**: add people or remove them with the **×**. Click **Save Changes**.
