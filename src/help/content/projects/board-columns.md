## 1. Open Board columns

On the project's **Board**, click **Board columns** at the top right.

## 2. Change the columns

![Board columns](1-columns.webp "Each column counts as one of four stages")

1. Type a new name to rename a column [[1]].
2. **Counts as** [[2]] tells PMT what the column means: *Not started*, *In progress*, *Review* or *Done*. Reports, overdue alerts and the Timeline use it. For example, *Testing* counts as *Review*.
3. Drag the dots on the left to change the order. Remove a column you don't need with the bin [[3]].
4. **Add column** [[4]], then **Save columns**.

:::note A start and an end always stay
There must always be at least one column that counts as *Not started* and one that counts as *Done*. Their bin shows a lock instead. When you remove a column that still has tasks, PMT asks which column they move to.
:::
